# NeuralConsult Sevrage

High-fidelity, mobile-first smoking cessation platform (Web + PWA) with a Spring Boot backend, React frontend, and AI service.

## Structure
- backend: Spring Boot 3.x API, Security (JWT), PostgreSQL
- frontend: React 18 + TypeScript + Tailwind + shadcn/ui
- ai-service: Python AI services (RAG, Gemini integration)
- database: SQL schema and seeds
- docker: Multi-stage Dockerfiles
- docs: Architecture notes and specs
